## 1. 产品概述

Zero Token Chat 是一款无需 API Token 的多模型 AI 聊天应用，通过复用用户在 DeepSeek 和 Qwen 官网的登录凭证（Cookies/Token），实现零成本调用主流 AI 大模型。目标用户为个人开发者、研究者和 AI 爱好者，核心价值在于打破 AI 模型访问的经济壁垒。

- 通过浏览器 Cookie 认证方式，免费使用 DeepSeek V4 Pro（专家模式）和 Qwen3.7 Max
- 提供 ChatGPT 风格的聊天界面，支持流式输出、思考模式、工具调用和网页搜索
- 同时支持 Web 端和 Windows 桌面端（Tauri 2 打包）

## 3. 核心流程

### 3.1 Cookie 导入流程

1. 用户点击"导入 Cookie"按钮
2. 应用使用系统默认浏览器打开对应官网（DeepSeek / Qwen）
3. 用户在浏览器中完成登录
4. 用户从浏览器 DevTools 中复制 Cookie/Token
5. 用户将 Cookie/Token 粘贴到应用中
6. 应用验证 Cookie 有效性并加密保存到本地
7. 后续请求自动携带 Cookie 调用模型 API

### 3.2 聊天流程

1. 用户选择模型（DeepSeek V4 Pro / Qwen3.7 Max）
2. 用户输入消息并发送
3. 后端使用保存的 Cookie 构造请求，发送到对应平台 API
4. 后端通过 SSE 流式接收响应
5. 前端实时渲染流式内容（包括思考过程、工具调用、搜索结果）
6. 对话历史本地保存

### 3.3 工具调用流程

1. 模型返回包含工具调用指令的响应
2. 后端解析工具调用指令（XML 格式或原生 tool_calls）
3. 后端在本地沙箱中执行工具（代码执行、文件操作等）
4. 将工具执行结果返回给模型继续生成
5. 前端展示工具调用过程和结果

## 5. Cookie 导入流程详细设计

### 5.1 DeepSeek Cookie 导入

**所需凭证**：
- `userToken`：从 `chat.deepseek.com` 的 localStorage 获取
- 浏览器 Cookie：`intercom-device-id-dgkjq2bp` 等

**获取步骤**：
1. 打开 `chat.deepseek.com` 并登录
2. 按 F12 打开开发者工具
3. 切换到 Console 标签
4. 输入 `localStorage.getItem('userToken')` 并回车
5. 复制返回的 token 值（不含引号）
6. 粘贴到应用的 DeepSeek Token 输入框中

### 5.2 Qwen Cookie 导入

**所需凭证（国际版 chat.qwen.ai）**：
- `token`：从 `chat.qwen.ai` 的 localStorage 获取

**获取步骤**：
1. 打开 `chat.qwen.ai` 并登录
2. 按 F12 打开开发者工具
3. 切换到 Console 标签
4. 输入 `localStorage.getItem('token')` 并回车
5. 复制返回的 token 值（不含引号）
6. 粘贴到应用的 Qwen Token 输入框中

### 5.3 Cookie 安全存储

- 所有凭证使用 AES-256 加密后存储在本地
- 加密密钥基于机器特征码生成（无需用户记忆密码）
- 存储位置：`~/.zero-token-chat/credentials.enc`
- 支持手动清除所有凭证
