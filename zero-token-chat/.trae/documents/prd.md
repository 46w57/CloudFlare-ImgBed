## 1. 产品概述

Zero Token Chat 是一款无需 API Token 的多模型 AI 聊天应用，通过自动导出用户在 DeepSeek 和 Qwen 官网的登录凭证，实现零成本调用主流 AI 大模型。目标用户为个人开发者、研究者和 AI 爱好者，核心价值在于打破 AI 模型访问的经济壁垒。

- 通过自动读取浏览器 Cookie/Token，免费使用 DeepSeek V4 Pro（专家模式）和 Qwen3.7 Max
- 提供 ChatGPT 风格的聊天界面，支持流式输出、思考模式、工具调用和网页搜索
- 同时支持 Web 端和 Windows 桌面端（Tauri 2 打包）

## 3. 核心流程

### 3.1 Cookie 自动导出流程（核心）

1. 用户点击"登录 DeepSeek"或"登录 Qwen"按钮
2. 应用使用系统默认浏览器打开对应官网登录页面
3. **应用后台启动轮询**，自动检测浏览器 Cookie 数据库变化
4. 用户在浏览器中完成登录
5. **应用自动检测到新 Cookie/Token**，从浏览器存储中提取
6. 应用验证 Cookie 有效性并加密保存到本地
7. 前端显示"登录成功"状态
8. 后续请求自动携带凭证调用模型 API

**自动导出技术方案**：
- 使用 `rookiepy` 库自动读取 Chrome/Edge/Firefox 的 Cookie 数据库
- 使用自定义 LevelDB 读取器提取 localStorage 中的 Token
- 后台轮询间隔 2 秒，最长等待 5 分钟
- 检测到有效凭证后自动停止轮询

```mermaid
flowchart TD
    "用户点击登录按钮" --> "打开默认浏览器"
    "打开默认浏览器" --> "启动后台轮询"
    "启动后台轮询" --> "用户在浏览器中登录"
    "用户在浏览器中登录" --> "检测到新Cookie/Token"
    "检测到新Cookie/Token" --> "验证凭证有效性"
    "验证凭证有效性" --> "加密保存到本地"
    "加密保存到本地" --> "前端显示登录成功"
```

### 3.2 聊天流程

1. 用户选择模型（DeepSeek V4 Pro / Qwen3.7 Max）
2. 用户输入消息并发送
3. 后端使用保存的凭证构造请求，发送到对应平台 API
4. 后端通过 SSE 流式接收响应
5. 前端实时渲染流式内容（包括思考过程、工具调用、搜索结果）
6. 对话历史本地保存

### 3.3 工具调用流程

1. 模型返回包含工具调用指令的响应
2. 后端解析工具调用指令（XML 格式或原生 tool_calls）
3. 后端在本地沙箱中执行工具（代码执行、文件操作等）
4. 将工具执行结果返回给模型继续生成
5. 前端展示工具调用过程和结果

## 5. Cookie 自动导出详细设计

### 5.1 DeepSeek 凭证自动导出

**所需凭证**：
- `userToken`：从 `chat.deepseek.com` 的 localStorage 获取（存储在浏览器 LevelDB 中）
- 浏览器 Cookie：从 Chrome/Edge Cookie 数据库自动读取

**自动导出流程**：
1. 点击"登录 DeepSeek"→ 打开 `chat.deepseek.com`
2. 后台使用 `rookiepy` 轮询读取浏览器 Cookie
3. 后台使用 LevelDB 读取器提取 localStorage 中的 `userToken`
4. 检测到有效凭证后自动保存

**手动备选**：如自动导出失败，提供手动粘贴 Token 的输入框

### 5.2 Qwen 凭证自动导出

**所需凭证（国际版 chat.qwen.ai）**：
- `token`：从 `chat.qwen.ai` 的 localStorage 获取
- 浏览器 Cookie：从 Chrome/Edge Cookie 数据库自动读取

**自动导出流程**：同 DeepSeek

### 5.3 凭证安全存储

- 所有凭证使用 AES-256-GCM 加密后存储在本地
- 加密密钥基于机器特征码生成（无需用户记忆密码）
- 存储位置：`~/.zero-token-chat/credentials.enc`
- 支持手动清除所有凭证
